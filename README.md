# 🤖 CLI Assistant

A simple terminal-based AI assistant built with Python and Groq (OpenAI-compatible API).  
It allows you to chat with a large language model directly from the command line with memory, logging, and persistent history.

---

## 🚀 Features

- 💬 Chat with LLM via CLI
- 🧠 Conversation memory (context-aware responses)
- 💾 Persistent chat history (JSON storage)
- 📊 Logging system (console + file logs)
- ⚡ Fast responses via Groq API
- 🔐 Secure environment variable usage (.env)

---

## 🛠️ Tech Stack

- Python 3.10+
- OpenAI SDK (Groq-compatible API)
- python-dotenv
- JSON for storage
- logging module
